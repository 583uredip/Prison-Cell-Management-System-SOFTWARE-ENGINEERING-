The Prison Cell Management System (PCMS) is an effective software based solution that improves the management of prisoner related information and daily operations of prisons. It replaces the traditional paper-based record keeping methods in an effort to reduce data inconsistency, unauthorised access and difficulty retrieving important information. Role-based access control is implemented to ensure that each user can only perform the tasks permitted according to their responsibilities. This includes the Administrator, Warden, Jailer and Medical Officer.The project follows the V-Model software development process which provides systematic planning, implementation, verification and validation of the system. The system is planned to be reliable, secure and accurate through proper requirement analysis, design, testing and documentation. Prisoner registration, cell allocation, medical record management, authentication, input validation etc. are helpful in efficient prison administration. ThePCMS is an instance of applying software engineering principles to real-world management problems. It also enhances operational efficiency, protects sensitive information, and offers a structured platform for managing prison records. Future work can add more features to this system like external database integration, biometric support and advance monitoring systems.
